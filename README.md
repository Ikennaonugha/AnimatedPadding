# AnimatedPadding in Flutter

A simple, interactive Flutter project demonstrating the use of the AnimatedPadding widget to dynamically animate layout spacing.

## Overview

The AnimatedPadding is simply the animated version of the Padding widget. It is used to dynamically change a widget's padding for UI effects like zooming or shrinking an asset e.t.c.


## Key UI Components

• AppBar: Displays the title "AnimatedPadding" at the top.

• AnimatedPadding: The core widget wrapping the target widget.

• ElevatedButton: This is to trigger the change.

## How to Run the Project
`
flutter run
`
