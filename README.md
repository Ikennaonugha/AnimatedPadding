# AnimatedPadding in Flutter

A simple, interactive Flutter project demonstrating the use of the AnimatedPadding widget to dynamically animate layout spacing.

## Overview

The AnimatedPadding widget is an animated version of Flutter's standard Padding widget. It is used to dynamically transition a widget's padding over a specified duration—perfect for UI effects like zooming into an image, shrinking an asset, or creating smooth, responsive layouts.


## Key UI Components

• AppBar: Displays the title "AnimatedPadding" at the top.
• AnimatedPadding: The core widget wrapping the target widget.
• ElevatedButton: This is to trigger the change.

## How to Run the Project
`
flutter run
